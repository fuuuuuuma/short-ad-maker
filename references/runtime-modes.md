# Runtime Modes

Skill Installerが導入するのは、制作判断、テンプレート、初期化、検証の仕組み。動画・音声生成サービスやアカウントは同梱しない。開始前に次のモードを選ぶ。

## フルAIモード

画像または動画生成、音声生成、音声認識、MP4編集の能力が使える環境。商品画像や説明だけから完結できる。外部サービスが課金を伴う場合は、実行直前に対象と費用を確認する。

## 手元素材モード

ユーザーが動画または写真とナレーションを提供し、編集と音声認識が使える環境。生成サービスがなくても、素材の構成、字幕、BGM、SE、MP4検証まで進める。

## 静止画モーションモード

商品写真とナレーションがあり、FFmpeg相当の編集能力だけが使える環境。パン、ズーム、クロップ、マスク、短い文字演出で縦型MP4を作る。人物の実演を捏造せず、商品マクロ、使い方の図解、利用場面の写真で構成する。

## 開始条件

最低でも、映像にできる素材、ナレーション、MP4編集、字幕時刻を取得する音声認識が必要。欠けている場合は、必要な能力または代替素材を一度だけ示し、完成できない状態で生成を開始しない。
